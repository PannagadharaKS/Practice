### ARRAY 2

```
    E1. SET MISMATCH
        * FREQUENCY ARRAY / COUNTING SORT
        = FREQUENCY ARRAY WITH MORE THAN 1 COUNT = DUPLICATE, ITEM WITH 0 VALUE = MISSING
    
    E2. SMALLER THAN THE CURRENT NUMBER
        * FREQUENCY ARRAY + RANKING

    E3. FIND DISAPPEARED NUMBER

```

### STACK

```
    E1. BUILD AN ARRAY WITH STACK
        * EXISTENCE ARRAY
        = IN STREAM, IF ITEM IS 1 IN EXISTENCE ARRAY, THEN PUSH ELSE POP

    E2. REVERSE POLISH NOTATION
        * ARITHMETIC LISTENER
        = IN STREAM, IF ITEM IS AN OPERATION THEN, POP 2 ITEMS AND EXECUTE ELSE PUSH TO STACK
    
    E3. EXCLUSIVE TIME OF FUNCTIONS
        * FREQUENCY ARRAY + MAINTAIN ID STACK
        = IN STREAM, IF ITEM IS START THEN, ADD UNITS - PREV ELSE IF END THEN, UNITS - PREV + 1 THEN POP
```
