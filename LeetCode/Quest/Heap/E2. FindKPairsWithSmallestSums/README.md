<p align='center' >FIND K PAIRS OF SMALLEST SUMS</p>

## VISUALIZATION

1. INPUT: 
    NUMS1 = [1,7,11]
    NUMS2 = [2,4,6]
    K = 3

2. INIT: 
    VISITED_PAIRS = NEW SET()
    RESULT = []
    I, J = 0, 0
    HEAP = [[0, 0]]

3. INIT FUNCTIONS:
    HEAPIFY_DOWN(HEAP, I, N)
    HEAPIFY_UP(HEAP, N - 1)
    EXTRACT_MIN_AND_HEAPIFY()
    INSERT_INTO_HEAP(VALUE: [I, J])

4. 

## ALGORITHM

0. START
1. INIT: 
    VISITED_PAIRS = NEW SET()
    RESULT = []
    I, J = 0, 0
    HEAP = [[0, 0]]

   INIT FUNCTIONS:
    HEAPIFY_DOWN(HEAP, I, N)
    HEAPIFY_UP(HEAP, N - 1)
    EXTRACT_MIN_AND_HEAPIFY()
    INSERT_INTO_HEAP(VALUE: [I, J])
2. ITERATE TILL RESULT.LENGTH = K
2.1. CALL EXTRACT_MIN_AND_HEAPIFY() TO RETRIEVE I AND J
2.1.1. POP THE FIRST [I, J] FROM THE MIN PAIRS HEAP
2.1.2. CALL HEAPIFY_DOWN() FOR THE UPDATED HEAP
2.2. BEFORE GOING FURTHER, CHECK IF I AND J ALREADY BEEN ADDED TO VISITED_PAIRS SET
2.2.1 IF YES, THEN CONTINUE TO NEXT ITERATION
2.3. PUSH [I, J] TO RESULT
2.4. SET I_J IN VISITED_PAIRS SET
2.5. CHECK IF I+1, J IS PRESENT IN VISITED_PAIRS, IF FALSE THEN, CALL INSERT_INTO_HEAP()
2.6. CHECK IF I, J+1 IS PRESENT IN VISITED_PAIRS, IF FALSE THEN, CALL INSERT_INTO_HEAP()
3. RETURN RESULT
4. END
