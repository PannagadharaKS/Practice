<p align='center' >REVERSE POLISH NOTATIONS</p>

## VISUALIZATION (OPTIMIZED)

1. INPUT = ["2","1","+","3","*"]

2. INITIALIZE OPERATIONS
    +: A + B
    -: B - A
    *: A * B
    /: NEAR_TO_ZERO(B / A)

3. ["2","1","+","3","*"]
    2 
    2, 1 
    2, 1, + ---> 2 + 1 ---> 3
    3, 3, * ---> 3 * 3 ---> 9
    9

4. OUTPUT = 9

## APPROACH

1. INITIALIZE OPERATIONS AND STACK
2. FOR EACH TOKEN
    2.1 IF TOKEN IS AN OPERATION
        2.2 POP 2 TOKENS [RHS & LHS]
        2.3 EVAL POPPED TOKENS USING OPERATIONS
        2.4 PUSH TO THE STACK
    2.2 OTHERWISE,
        2.3. PUSH THE NUMBER TO THE STACK
3. OUTPUT THE NUMBER REMAINED IN THE STACK

## REMEMBERING POINTS

1. BUILT IN EVAL() METHOD IS SLOWER AND HENCE PREFER MANUAL FUNCTION
2. MATH.FLOOR AND MATH.CEIL ARE EXTRA BUILT IN FUNCTIONS WHICH IS SLOWER THAN MATH.TRUNC
3. FOR INCREASING ANY NUMBER,
    3.1 ORDER DOESNT MATTER
4. FOR DECREASING ANY NUMBER,
    4.1, RHS SHOULD BE AT THE START
