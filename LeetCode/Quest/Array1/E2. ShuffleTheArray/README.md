1. SPLIT MAIN ARRAY INTO 2 ARRAYS USING n VIA .slice()
2. APPEND EACH ITEM FROM BOTH THE ARRAY TO THE OUTPUT ARRAY
3. BREAK THE LOOP WHEN THERE ARE NO ITEMS TO APPEND
