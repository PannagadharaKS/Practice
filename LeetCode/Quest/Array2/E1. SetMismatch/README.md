<p align='center' >SET MISMATCH</p>

## APPROACH 1

1. SINCE THE NUMBERS ARE FINITE, INITIALIZE AN EMPTY ARRAY CONSISTS OF 0'S
2. INCREMENT ARRAY CONTAINING 0'S WHENEVER THE NUMBER APPEARS IN THAT INDEX
3. IF NUMBER APPEARED TWICE, THEN IT IS A DUPLICATE
4. IF NUMBER DOESNT APPEAR, THEN IT IS MISSING

## APPROACH 2

1. USING MULTIPLE SET TO CHECK IF THE NUMBERS ARE OCCURING AND FINDING OUT THE MISSING NUMBER
2. INEFFICIENT THAN 1ST APPROACH SINCE MEMORY USED IS MORE BECAUSE OF THE SET.
