<p align='center' >REPEATED SUBSTRING PATTERN</p>

## VISUALIZATION

1. INPUT S = "abab"

2. S + S
   "abab" + "abab"
   "abababab"

3. (S + S).SLICE(1, -1)
   "abababab"
     |    |

4. (S + S).SLICE(1, -1).INCLUDES(S)
   "bababa" HAS abab

5. RETURN TRUE

## ALGORITHM

0. START
1. DOUBLE THE INPUT STRING
2. SLICE THE DOUBLED INPUT STRING BY REMOVING FIRST AND LAST LETTER
3. CHECK IF INPUT STRING IS PRESENT IN THE SLICED STRING
4. RETURN THE OUTCOME
5. END
