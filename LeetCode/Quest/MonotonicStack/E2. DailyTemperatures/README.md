## VISUALIZATION

1. TEMPERATURES = [30,40,50,60] <!-- INPUT -->

2. INIT ANS = [...TEMPERATURES AS 0] = [0, 0, 0, 0, 0] <!-- INIT ANS = EMPTY 0'S -->
   INIT IMS = [0] <!-- INIT IMS FOR STORING INDEXES STARTING FROM 0 -->

3. LOOP< 1 .. TEMPERATURES.LENGTH > <!-- LOOP 1 .. TEMPERATURES.LENGTH -->
   I = 1
        WHILE(1 && TEMPERATURES[0] < TEMPERATURES[1]) <!-- WHILE <STACK.LENGTH> & TEMPERATURES[TOP] < TEMPERATURES[I] -->
            - POP 0 FROM IMS
            - ANS[0] = 1 - 0 = 1 <!-- ANS[TOP] = I - TOP -->
        - IMS = [1] <!-- PUSH IMS(I) -->
        
4. I = 2
        WHILE(1 && TEMPERATURES[1] < TEMPERATURES[2])
            - POP 1 FROM IMS
            - ANS[1] = 2 - 1 = 1 <!-- ANS[TOP] = I - TOP -->
        - IMS = [2] <!-- PUSH IMS(I) -->

5. I = 3
        WHILE(1 && TEMPERATURES[2] < TEMPERATURES[3])
            - POP 2 FROM IMS
            - ANS[2] = 3 - 2 = 1 <!-- ANS[TOP] = I - TOP -->
        - IMS = [3] <!-- PUSH IMS(I) -->

6. ANS = [1, 1, 1, 0]

## ALGORITHM

0. START
1. INIT ANS = 0'S OF TEMPERATURES.LENGTH,
   INIT IMS = [0]
2. ITERATE FROM INDEX 1 TO TEMPERATURES LENGTH
3. WHILE 
    - IMS HAS ANY INDEX 
        AND
    - TEMPERATURES[IMS[TOP]] < TEMPERATURES[I]
4. IF TRUE, THEN 
    - POP FROM IMS
    - ANS[IMS[TOP]] = I - POPPED_IMS[TOP]
5. PUSH I TO IMS
6. RETURN ANS
7. END

## REMEMBERING POINTS

1. IN IMS, RATHER THAN STORING THE ACTUAL ITEM, STORE THE INDEX AS THE ORDER IS PRESENT BY DEFAULT
2. PEEK INSTEAD OF POPPING THE ELEMENT TO FETCH THE TOP ITEM IN A STACK
3. IT WONT BE AN OVERLOAD IF 2 OR MORE ARRAYS INITIALIZED WHEN TEMPERATURES LENGTH IS FINITE
4. DONT GET TANGLED UP BETWEEN WRITTEN APPROACH & PROGRAMMING APPROACH, JUST REMEMBER THE LOGIC
5. COPY OF 0'S & INDEXES ARE ALWAYS OCCUPIES LESS MEMORY COMPARED TO ACTUAL ITEMS
