## VISUALIZATION

1. PRICES = [8, 4, 6, 2, 3] <!-- INPUT -->

2. INIT ANS = [...PRICES] = [8, 4, 6, 2, 3] <!-- INIT ANS = COPY OF PRICES -->
   INIT MONO_STACK = [0] <!-- INIT MONO_STACK FOR STORING INDEXES STARTING FROM 0 [IMS] -->

3. LOOP< 1 .. PRICES.LENGTH > <!-- LOOP 1 .. PRICES.LENGTH -->
   I = 1
        WHILE(1 && PRICES[0] >= PRICES[1]) <!-- WHILE <STACK.LENGTH> & PRICES[TOP] >= PRICES[I] -->
            - POP 0 FROM MONO_STACK
            - ANS[0] = PRICES[0] - PRICES[1] = 8 - 4 = 4 <!-- ANS[TOP] = PRICES[TOP] - PRICES[I] -->
        - MONO_STACK = [1] <!-- PUSH MONO_STACK(I) -->
        
4. I = 2
        WHILE(1 && PRICES[1] >= PRICES[2])
            <!-- NOTHING -->
        - MONO_STACK = [1, 2]

5. I = 3
        WHILE(1 && PRICES[2] >= PRICES[3])
            - POP 2 FROM MONO_STACK
            - ANS[2] = PRICES[2] - PRICES[3] = 6 - 2 = 4

            - POP 1 FROM MONO_STACK
            - ANS[1] = PRICES[1] - PRICES[3] = 4 - 2 = 2
        - MONO_STACK = [3]

6. I = 4
        WHILE(1 && PRICES[3] >= PRICES[4])
            <!-- NOTHING -->
        - MONO_STACK = [3, 4]

7. ANS = [4, 2, 4, 2, 3]

## ALGORITHM

0. START
1. INIT ANS = COPY OF PRICES,
   INIT MONO_STACK = [0]
2. ITERATE FROM INDEX 1 TO PRICES LENGTH
3. WHILE 
    - MONO_STACK HAS ANY INDEX 
        AND
    - PRICES[MONO_STACK[TOP]] >= PRICES[I]
4. IF TRUE, THEN 
    - POP FROM MONO_STACK
    - ANS[MONO_STACK[TOP]] = PRICES[MONO_STACK[TOP]] - PRICES[I]
5. PUSH I TO MONO_STACK
6. RETURN ANS
7. END

## REMEMBERING POINTS

1. IN IMS, RATHER THAN STORING THE ACTUAL ITEM, STORE THE INDEX AS THE ORDER IS PRESENT BY DEFAULT
2. PEEK INSTEAD OF POPPING THE ELEMENT TO FETCH THE TOP ITEM IN A STACK
3. IT WONT BE AN OVERLOAD IF 2 OR MORE ARRAYS INITIALIZED WHEN PRICES LENGTH IS FINITE
4. DONT GET TANGLED UP BETWEEN WRITTEN APPROACH & PROGRAMMING APPROACH, JUST REMEMBER THE LOGIC
