<p align='center'>TREE</p>

# Summary
```
    - Sorted Order with Efficient Search / Insert / Delete Operations
```

# CRUD Operations
```
    CREATE
        - Initialize ROOT NODE / NODE with LEFT & RIGHT PONTERS / CHILDREN
    READ
        - Traversing LEFT / RIGHT subtrees
    UPDATE
        - Traverse to the NODE
        - Update the value
    DELETE
        - Delete maintaining Tree structure
            - Delete LEAF
            - Delete 1 CHILD
            - Delete 2 CHILDREN
```

# Time Complexity
```
    CREATE
        - O(1)
    READ
        - O(logN)
    UPDATE
        - O(logN)
    DELETE
        - O(logN)
```
