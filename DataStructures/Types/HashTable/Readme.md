<p align='center'>HASH TABLE</p>

# Summary
```
    - Efficient & Fast CRUD Operations
```

# CRUD Operations
```
    CREATE
        - Create KEY VALUE Pair
    READ
        - Retrieve the VALUE for a given KEY
    UPDATE
        - Modify the VALUE for an existing KEY
    DELETE
        - Delete the KEY VALUE Pair from the hash table
```

# Time Complexity
```
    CREATE
        - O(1)
    READ
        - O(1)
    UPDATE
        - O(1)
    DELETE
        - O(1)
```
