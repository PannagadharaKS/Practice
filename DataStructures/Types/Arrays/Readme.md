<p align='center'>ARRAYS</p>

# Summary
```
    Fast Indexed Access in Contiguous / Sequential Block of Memory
```

# CRUD Operations
```
    CREATE
        - Initialize 0 / N Items
    READ
        - Access via the Index
    UPDATE
        - Update by assigning value via the Index
    DELETE
        POP
            - Delete the Last Item
        SHIFT
            - Delete the First Item
        SWAP & SHIFT / POP
            - Swap the required Item to the First Item & SHIFT / Last Item & POP
```

# Time Complexity
```
    CREATE
        - O(1)
    READ
        - O(1)
    UPDATE
        - O(1)
    DELETE
        POP
            - O(1)
        SHIFT
            - O(1)
        SWAP & SHIFT / POP
            POP
                - O(1)
            SHIFT
                - O(n)
            
```
